The environment used for developing the code to solve the exercise is the CERN LCG sotfware stack [Release 110](https://lcginfo.cern.ch/release_packages/110/x86_64-el9-gcc16-opt/). The environment can be setup by running
```bash
source /cvmfs/sft.cern.ch/lcg/views/LCG_110/x86_64-el9-gcc13-opt/setup.sh
```
Inside each subfolder, `SOLUTION_README.md` files provide instructions on how to run the solutions.
