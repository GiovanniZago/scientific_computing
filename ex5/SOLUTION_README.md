Compile and run using the following commands. The solution uses the GNU GSL implementation of the Legendre polynomials, so the library path and the link flags should be specified.
```bash
gcc -L/cvmfs/sft.cern.ch/lcg/views/LCG_110/x86_64-el9-gcc13-opt/lib main.c -o main.out -lgsl -lgslcblas

./main.out

```
The `plotter.py` Python script takes the `out.csv` file generated by the program and creates the comparison plot for each `x` value for which the calculation of the Legendre polynomials has been requested.
